# apidex

APIを調査・ドキュメント化するためのローカルツール。
APIを叩きながら仕様を解明し、蓄積した結果から **OpenAPI YAML を自動生成** します。

---

## 特徴

- **認証方式を動的切り替え** — Bearer Token / APIキー(ヘッダー・クエリ) / なし に対応。認証方式が不明な段階からでも使い始められます
- **リクエストを自動蓄積** — 叩くたびにリクエスト・レスポンスをローカルのSQLiteに保存
- **バッチ実行** — CSVでエンドポイント一覧を渡して一括実行。1件失敗しても残りを継続し、結果をまとめて確認できます
- **OpenAPI YAML を自動生成** — 蓄積データからスキーマを推論し、複数回のレスポンスをマージしてより正確なドキュメントを生成
- **ローカル完結** — 外部サービスへのデータ送信なし。社外秘APIの調査にも安心

## セットアップ

**動作環境**: Python 3.11 以上

```bash
# リポジトリをクローン（またはディレクトリへ移動）
cd api-exploer

# 仮想環境を作成・有効化
python3 -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate

# 依存ライブラリをインストール
pip install -r requirements.txt
```

## 起動

```bash
streamlit run app.py
```

ブラウザで `http://localhost:8501` が自動的に開きます。
DBファイル `api_explorer.db` は初回起動時に自動生成されます。

> **初回起動時の注意**: Streamlit のメール登録プロンプトが表示されます。サポートを希望しない場合はメールアドレスをブランクのままEnterを押してください。

## 使い方

### 1. APIを叩く

1. **メソッド** と **ベースURL**（例: `https://api.example.com`）を入力
2. **エンドポイント**（例: `/api/v1/users`）を入力
3. **認証方式** を選択して認証情報を入力
4. 必要に応じてヘッダー・クエリパラメータ・ボディを JSON 形式で入力
5. **「送信」** ボタンをクリック

レスポンスとリクエスト詳細は画面右側に表示され、DBへ自動保存されます。

> **URLからパース**: クエリパラメータ付きの完全なURL（例: `https://api.example.com/v1/forecast?latitude=35.68&longitude=139.68`）をそのままペーストして各フィールドに自動入力することもできます。

### 2. ログを確認する

「ログ一覧」セクションで過去のリクエストを確認できます。
各ログをクリックするとリクエスト・レスポンスの詳細が展開されます。

### 3. OpenAPI YAML を生成する

1. 「OpenAPI YAML 生成」セクションでベースURLを選択
2. API タイトルを入力
3. **「YAML を生成」** ボタンをクリック
4. 生成された YAML を確認し、**「YAML をダウンロード」** で保存

> 同じエンドポイントを複数回叩くほど、スキーマの精度が上がります。

### 4. バッチ実行する

1. 「バッチ実行」セクションでベースURLと認証方式を設定
2. CSVファイルをアップロード
3. **「バッチ実行」** ボタンをクリック
4. プログレスバーで進捗を確認し、完了後に成功/失敗の一覧を確認

**CSVフォーマット**（`params`・`body` 列は省略可）:

```csv
method,endpoint,params,body
GET,/api/v1/users,,
GET,/api/v1/users/1,,
POST,/api/v1/orders,,"{""item"": ""abc""}"
GET,/api/v1/products,"{""page"": 1}",
```

> 1件失敗しても残りのリクエストを継続します。全件の実行結果はログに自動保存されます。

## 対応認証方式

| 認証方式 | 説明 |
|---------|------|
| なし | 認証情報を付与しない |
| Bearer Token | `Authorization: Bearer {token}` ヘッダーを付与 |
| APIキー(ヘッダー) | 任意のヘッダー名でAPIキーを付与 |
| APIキー(クエリ) | クエリパラメータとしてAPIキーを付与 |

## プロジェクト構成

```

├── app.py                  # Streamlit UI（エントリーポイント）
├── requirements.txt
├── auth/
│   └── strategies.py       # 認証Strategyパターン
├── core/
│   ├── client.py           # HTTPリクエスト実行・ログ記録

│   ├── batch.py            # CSVパース（バッチ実行用）
│   └── url_parser.py       # URLパース（ベースURL・エンドポイント・クエリパラメータ分解）
├── db/
│   ├── models.py           # SQLAlchemyモデル
│   └── repository.py       # DB操作
├── openapi/
│   └── generator.py        # OpenAPI YAML生成
└── tests/                  # pytestテスト群
```
